# Blog uploads

Drop a `.zip` file here (on GitHub: **Add file → Upload files**, then **Commit changes**).
Each zip should contain one `.txt` article and one image. The site rebuilds automatically and
the post appears at `/blog/<post-title>/` within a few minutes. The zip is removed after it is published.

See `BLOG-UPLOAD-GUIDE.md` in the repository root for the article format.
